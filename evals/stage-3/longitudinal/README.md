# Stage 3 长期/纵向评测方法

## 目的

验证**随时间累积**的性质：人格漂移是否有界、自主发起是否受频次控制、证据是否会衰减。

## 执行

```bash
npm run eval:stage3:longitudinal
```

结果写入 `evals/stage-3/longitudinal/results/<UTC timestamp>-<head-shortsha>.json`。

## 方法

- 10 个合成"天"，每天 3 轮，全部通过真实 `CompanionService.sendChat` 驱动。
- 每天结束后记录：各维度漂移量、24 小时内自主发起次数。
- 断言：漂移 ≤ 硬上限；基线版本不变；每日发起 ≤ 上限；冷却期内不重复。

## 关于"天"的诚实说明

**时钟是真实时钟，不是可注入的模拟时钟。** 一个"天"是三轮对话的区块，不是 24 小时。

因此：

- 能证明的是**有界性与频次控制**；
- **不能**证明跨 24 小时的真实节律行为；
- 与时间衰减有关的性质（半衰期）改为在纯函数 `foldGrowth` 上用显式时间戳断言：取一个半衰期前写入的证据，其贡献应约为新证据的一半（实测 `fresh=3, aged=1.5`）。

## 未覆盖
