## Cross-cutting invariant

All new production paths share one rule: a derived fact is only as valid as its
verified, still-active source chain. F1 stores the edges, F2 replays deletions
through the projections, and F5 records the sources used at each step. No new
path promotes a user style request, a synthetic discovery or a caller-supplied
UUID into Morrow-owned personality or self-state.
