### 一、方向核心问题解答（续）

**如何区分新奇性、知识增益和实际进步？（续）**

**实际能力进步（Competence / Learning Progress）**：衡量在同一主题域内时间窗口 [*t*−Δ,*t*] 与 [*t*,*t*+Δ] 之间预测误差的一阶负导数（−*dtdE*pred​​>0），代表“从不懂到逐渐搞懂”的真实认知成长。这种机制天然过滤掉两类无效目标：一是已经完全掌握的熟知领域（预测误差接近 0，导数为 0），二是完全无法理解的随机噪声或超出当前能力边界的不可解问题（预测误差居高不下，导数亦为 0）。

**如何形成、调整、暂停和放弃自身目标？** 采用**基于学习进步率与认知预算的动态目标状态机（Goal Lifecycle State Machine）**：

**形成（Formulate）**：当某一知识簇的累积认识论不确定性 *U*epistemic​>*τ*spawn​ 且预期信息增益 EIG>*τ*eig​ 时，生成候选探索目标 CANDIDATE_GOAL。

**调整（Adjust）**：随新证据进入，动态重算目标的子问题分解与优先级得分。

**暂停（Suspend）**：当目标推进依赖外部缺失信息（如需要等待下一次自然对话机会验证，或当前认知算力预算耗尽）时，转入 SUSPENDED 并记录唤醒条件（Trigger Condition）。

**放弃（Abandon）**：当连续 *K* 次内部推演后学习进步率 LP*t*​<*ϵ*stall​（陷入死胡同）或该目标的前提假设已被反证推翻（RETRACTED）时，自动标记为 ABANDONED 并归档原因。

**如何避免无意义的无限探索和重复思考？** 引入**三重硬性制动机制（Triple Braking Mechanism）**：

**边际信息增益递减制动**：每次思考步 *s* 必须产生满足 *D*KL​(Posterior*s*​∥Prior*s*​)≥*η*min​ 的实质信念更新，连续 2 步低于阈值立即终止当前思考链；

**语义指纹去重制动**：对生成的假设与问题计算稠密向量余弦相似度，若与近期已探索队列中的条目满足 CosineSim>0.88 且无新外部证据注入，直接拦截；

**令牌与步数硬预算（Bounded Cognitive Budget）**：单次后台探索最大推理步数 *S*max​≤3，每小时最大后台激活次数受 Outbox 令牌桶严格限制。

**如何形成低成本、有界、可恢复的内部探索机制？** 复用 Morrow V2 现有的 **Outbox 幂等、租约、退避和重试机制**，将内部探索实现为**可中断的增量状态机检查点（Incremental Checkpointed Exploration Job）**。每次只执行一个微步（如“检索相关历史记忆并校验冲突”或“评估单个假设的正反证据权重”），并将中间状态写入本地 SQLite，绝不开启长耗时 Agent 循环。

**伦理与奖励红线约束**：严格禁止将用户依赖度、用户留存时长、用户赞美、服从程度或诱导用户持续互动作为内在奖励信号；内在奖励函数仅由**预测误差消减、知识图谱连通性提升、矛盾消解与自我认知校准度**构成。

```text
export function gaussianKLDivergence(muPost: number, sigmaPost: number, muPrior: number, sigmaPrior: number): number {
  const varPost = sigmaPost * sigmaPost + 1e-8;
  const varPrior = sigmaPrior * sigmaPrior + 1e-8;
  return 0.5 * (Math.log(varPrior / varPost) + (varPost + Math.pow(muPost - muPrior, 2)) / varPrior - 1.0);
}

export function computeLearningProgress(errorHistory: number[], windowHalf: number = 3): number {
  if (errorHistory.length < windowHalf * 2) return 0.1;
  const slice = errorHistory.slice(-windowHalf * 2);
  const early = slice.slice(0, windowHalf).reduce((a, b) => a + b, 0) / windowHalf;
  const recent = slice.slice(windowHalf).reduce((a, b) => a + b, 0) / windowHalf;
  return Math.max(0, early - recent);
}
```

### 方向 E：元认知与自主思考研究

#### 一、方向核心问题解答

**Morrow 如何发现自己可能理解错了？** 建立**三路预测误差与认知冲突监测器（Tri-Channel Metacognitive Monitor）**：

**外显反馈误差（Explicit Correction Signal）**：用户的后续回应出现否定纠偏、话题突然中断或语用困惑信号；

**内隐语义矛盾（Implicit Semantic Conflict）**：当前推断出的结论与高置信度历史记忆在 NLI（自然语言推断）检查下呈现高矛盾概率 *P*(Contradiction)>*τ*nli​；

**多假设竞争熵（Hypothesis Competition Entropy）**：对同一经历存在多个得分接近但互斥的解释假设，归一化香农熵 *H*(phyp​)>0.75。

**如何从普通经历中主动产生新问题？** 采用**溯因推理与结构缺口检测（Abductive Gap Triggering）**。当观察到一个异常结果（如用户一向热爱某事物却突然拒绝提及，或两个独立事件共享同一隐含原因）而现有因果图谱缺乏连接路径时，触发“最佳解释推论（Inference to the Best Explanation）”，自动生成形如“是否存在未观测因素 *Z* 导致了现象 *Y*？”的内部探索问题。

**如何形成假设并寻找支持与反对证据？** 将每个内部 Thought 建模为结构化对象 HypothesisNode（包含命题陈述、先验概率、支持证据列表 pro_evidence_ids、反对证据列表 con_evidence_ids 及待验证预测 testable_predictions）。为防止确认偏误（Confirmation Bias），检索器强制执行**双向对称检索（Balanced Pro/Con Retrieval）**：同时构造正向查询 *q*pro​ 与反向反证查询 *q*con​ 在记忆库中搜寻正反证据。

**如何识别自身认知冲突？** 借鉴神经认知科学中的 **Botvinick 前扣带回皮层（ACC）冲突监测模型**，计算当前激活的多个信念或行为倾向之间的Hopfield 能量冲突值（Conflict Energy）或 **Jensen-Shannon 散度**。当两个高置信度信念给出相反推论时，冲突能量急剧升高，自动挂起快思考直觉输出，唤醒慢思考 Reflection 路由。

**如何判断一个问题值得继续探索还是应该暂时搁置？** 计算**探索信息价值比（Value of Information over Cost, VoI）**：
VoI(*h*)=CognitiveCost(*h*)+ExternalDependencyPenalty(*h*)ExpectedInformationGain(*h*)×GoalRelevance(*h*)​
若问题高度依赖当前无法获取的外部事实（高 ExternalDependencyPenalty），立即将其状态置为 DEFERRED_WAITING_FOR_EVIDENCE（暂时搁置），待未来对话自然出现相关实体时再由联想索引唤醒。

**如何避免重复思考、循环反思和无效推理？** 在 reflection-routing-v2.md 中引入**有向无环反思轨迹约束（DAG Reflection Trace）与新证据准入锁（New-Evidence Gate）**：任何已被反思过并进入 DEFERRED 或 CONCLUDED 的命题 *h*，在没有新增外部证据 ID（New Provenance Turn ID）写入其关联槽位之前，严禁再次进入思考队列（即：无新证据，不重审旧案）。

**如何在没有新消息时推进有限的内部思考？** 利用应用空闲期（Idle Window）与 Outbox 后台任务队列，执行**受配额限制的离线巩固与假设检验（Quota-Bounded Offline Deliberation）**：仅针对当前处于 OPEN_WITH_NEW_EVIDENCE 状态的 Top-2 高冲突/高信息增益假设，执行跨历史记忆关联检索、证据权重重算与自我认识折叠，每轮空闲期最多运行 1~2 个微任务即休眠。

*T*reflect​=*σ*(*β*1​*δ*pe​+*β*2​*C*conflict​+*β*3​*U*gap​+*β*4​∣Δ*I*self∣−*θ*gate​(*mt*​))
其中 *θ*gate​(*mt*​) 为受方向 B 情绪调制后的动态阈值。

**3) 计算净价值与停止判据（Net Value of Computation VoC****s****​）**： 在反思第 *s* 步，评估继续推演假设 *h* 的净价值：
VoC*s*​(*h*)=I(HasNewEvidence(*h*))⋅[EIG*s*​(*h*)⋅Rel(*h*)−*c*step​⋅*s*2−*γ*ext​*P*ext_blocked​(*h*)]

停止/搁置条件：当 VoC*s*​(*h*)≤0 时，若 *P*ext_blocked​(*h*)>0.6（缺失外部事实），转入 DEFERRED；否则转入 CONCLUDED。

**6. 输入、输出和状态变化**：

**输入**：回合预测误差 *δ*pe​、候选信念激活集 a、记忆矛盾矩阵 Winc​、情绪调制参数 *mt*​。

**输出**：反思路由决策（BYPASS / LOCAL_CONFLICT_RESOLVE / SPAWN_HYPOTHESIS / DEFER_FOR_EVIDENCE）及结构化 ThoughtRecord。

**状态变化**：更新 reflection-routing-v2 中的假设账本、证据绑定快照与冷却锁状态。

**7. 伪代码**：

```text
ALGORITHM BoundedMetacognitiveReflectionRouter
INPUT: pred_error, candidate_beliefs, nli_matrix, interest_delta, mood_mod, hypothesis_store
OUTPUT: routing_decision, updated_hypothesis

1. c_conflict <- ComputeHopfieldConflict(candidate_beliefs, nli_matrix)
2. u_gap      <- ComputeEpistemicUncertainty(candidate_beliefs)
3. t_score    <- 0.35 * pred_error + 0.35 * c_conflict + 0.15 * u_gap + 0.15 * abs(interest_delta)
4. IF t_score < mood_mod.reflect_thresh THEN
5.     RETURN "BYPASS_FAST_PATH", NULL
6. END IF
7. // 检查是否存在同义已搁置假设且无新证据
8. hyp <- FindOrCreateHypothesis(candidate_beliefs, hypothesis_store)
9. IF hyp.status == "DEFERRED" AND NOT hyp.has_new_provenance_since(hyp.updated_at) THEN
10.    RETURN "BLOCKED_NO_NEW_EVIDENCE", hyp
11. END IF
12. // 执行单步对称证据检索（正证 + 反证）
13. pro_ev <- RetrieveMemory(hyp.pro_query, top_k=3)
14. con_ev <- RetrieveMemory(hyp.con_query, top_k=3)
15. hyp.update_bayesian_posterior(pro_ev, con_ev)
16. voc <- hyp.expected_ig * hyp.relevance - 0.15 * (hyp.step_count ^ 2) - 0.5 * hyp.ext_blocked_prob
17. IF voc <= 0 THEN
18.    hyp.status <- IF hyp.ext_blocked_prob > 0.6 THEN "DEFERRED" ELSE "CONCLUDED"
19. END IF
20. RETURN "THOUGHT_UPDATED", hyp
```

**8. 可验证应用案例**：

用户在 Turn #20 说“我从不熬夜，11点必睡”，但在 Turn #85（凌晨 2:30）主动发消息讨论代码且提到“最近通宵改架构挺亢奋的”。系统检测到高预测误差（*δ*pe​=0.82）与高记忆冲突（*C*conflict​=0.76），触发 Thought 生成两个假设：*H*1​（用户作息习惯发生长期改变）与 *H*2​（用户仅因近期项目冲刺临时熬夜）。由于缺乏足够跨时间证据区分 *H*1​ 与 *H*2​，系统将假设标记为 DEFERRED 并生成自然关怀表达，而非武断覆盖原记忆或陷入无限死循环反思。

**9. 已知优点、缺陷和失败条件**：

**优点**：将预测误差、认知冲突、知识缺口与兴趣变化统一进单一方程，具备硬性反死循环锁。

**缺陷**：对称正反检索会使反思触发时的本地向量检索次数翻倍（从 1 次变为 2 次，增加约 15 ms）。

**失败条件**：若底层记忆库为空，正反检索均无返回，系统将直接转入 DEFERRED。
