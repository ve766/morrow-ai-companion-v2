10. END FOR

12. pad_impulse <- Tanh(MatVecMul(W_PAD, I_t))
13. x_t <- mu_trait + ExpDiag(-Theta * dt) * (x_{t-1} - mu_trait) + pad_impulse
14. x_t <- ClipVec(x_t, -1.0, 1.0)

### 方向 C：人格形成与动态成长研究

#### 一、方向核心问题解答

**人格如何从长期经历而非预设标签中形成？** 采用**层级贝叶斯潜在特质模型（Hierarchical Bayesian Latent Trait Model）与全特质理论（Whole Trait Theory, Fleeson, 2001）**。人格特质 *θt*​∈R*K* 不由静态 Prompt 标签硬编码，而是被定义为跨时间、跨情境的行为与认知倾向分布的潜在后验均值（Latent Posterior Mean）。每一次真实的认知决策、情绪反应与价值权衡构成一次微观状态实现（State Manifestation），长期经历的密度分布峰值逐步沉淀为稳定特质。

**如何区分短期情绪、长期倾向、用户适配和 Morrow 自身人格？** 构建**四层状态空间解耦方程（Four-Layer State-Trait-Persona Decoupling）**：
*yt*​=Morrow 长期核心人格*θ*core,*t*​​​+面向用户的语用适配层Bauser_style,*t*​​​+短期情绪波动层Cxaffect,*t*​​​+*ϵt*​

*θ*core,*t*​：Morrow 自身跨会话核心特质（如求知欲、审慎度、共情基线、独立性），仅受经过严格独立性检验的长期自我经历与反思证据更新；

auser_style,*t*​：交互风格修辞参数（如措辞幽默度、回复简明度、语气柔和度），属于语用通信协议（Communication Accommodation），绝不反向写入 *θ*core,*t*​；

xaffect,*t*​：由 affective-state.md 管理的短期情绪状态，随时间回归至 *θ*core,*t*​ 决定的基线。

**如何防止一次事件直接改变人格？** 引入**样本量依赖的先验精度惯性（Sample-Size Dependent Prior Precision Inertia）与单步最大KL散度裁剪（Trust-Region KL Clipping）**。特质后验方差 *σθ*,*t*2​ 随累计有效证据量 *N*eff​ 增大而缩小，单次事件的卡尔曼增益 *Kt*​=*σθ*,*t*−12​+*σ*obs2​/*w*indep​*σθ*,*t*−12​​≪0.02，并在更新步施加硬上界 ∣Δ*θk*​∣≤Δmax​（如单次最多变动 0.005），从数学上杜绝单次事件扭转人格。

**如何识别跨时间、跨场景的稳定行为模式？** 引入**跨时间窗口与跨话题熵加权一致性检验（Cross-Temporal & Cross-Context Entropy Weighting）**。只有当某种倾向在 ≥*M* 个非连续时间桶（如跨越多天）且在 ≥*C* 个不同话题簇（Topic Clusters，通过方向 A 的 Embedding 聚类判定）中重复出现（高跨场景分布熵 *H*context​）时，才解除特质冻结门控（Consolidation Gate），将其计入核心特质增量。

**如何让人格既保持连续性，又能在证据充分时成长？** 采用**带遗忘因子的变分贝叶斯滤波（Variational Bayesian Filtering with Adaptive Plasticity ****γt****​）**。正常状态下精度累增保证高度稳定；当长期连续出现系统性、高独立性的新经历证据（累积惊喜度超过阈值）时，适度释放精度下界 *τ*min​，允许特质以周/月为时间尺度平滑迁移。

**如何通过反证修正、降级或撤回已有特质？** 每条特质维度维护正反双向证据累加器 (*αk*,*t*​,*βk*,*t*​) 及证据溯源链表 evidence_ledger。当出现真实反证（Counterevidence）时，增大反转证据计数 *βk*,*t*​，不仅拉低后验均值 *μk*,*t*​，同时增大认知不确定性方差，将特质置信等级从 ESTABLISHED 降级为 CONTESTED 或 TENTATIVE；若某历史记忆被证实为错误并撤回（Retracted），按溯源 ID 精确减去其曾贡献的 (Δ*α*,Δ*β*)。

**如何避免用户要求 Morrow 更幽默、更温柔，就直接变成 Morrow 自身人格？** 通过**言语行为路由隔离（Speech-Act Routing Isolation）**：当意图识别器检测到用户输入属于 USER_PREFERENCE_REQUEST 或 STYLE_INSTRUCTION（如“你以后说话幽默一点”）时，路由守卫强制将该信号定向至 user_interaction_style_profile（即上式中的 auser_style,*t*​），而对 *θ*core,*t*​ 的观测似然权重设为 0。Morrow 可以选择“为了照顾对方感受而在表达上更温和”，但其自我认识清楚记录“这是我对用户的沟通适配，而非我本性突变”。

**5. 数学公式与变量边界**：

**1) 跨时间与跨场景有效证据权重（Effective Evidence Weight）**： 给定第 *i* 条行为/反思观测事件 *ei*​（发生于时间 *ti*​、话题簇 *ci*​、极性得分 *zi*​∈[−1,1]），其进入人格账本的有效权重 *wi*​∈[0,1] 为：
*wi*​=I(source(*ei*​)=UserStyleCommand)⋅(1−exp(−*τ*cooldown​Δ*t*same_cluster​​))⋅*ρ*indep​(*ei*​)⋅*H*norm​(C*k*​)

**2) 正反双向证据 Beta-高斯共轭更新与可塑性-稳定性关系**： 对每个核心人格维度 *k*（取值归一化至 [−1,1]，对应 *z*~*i*​=2*zi*​+1​∈[0,1]），维护正向证据累积量 *αk*,*t*​ 与反向/反证累积量 *βk*,*t*​（初始先验 *αk*,0​=*βk*,0​=*ν*0​/2，其中 *ν*0​∈[20,50] 为先验等效样本量惯性）：
*αk*,*t*​=*γ*plasticityΔ*t*​*αk*,*t*−1​+*wi*​⋅max(0,*zi*​),*βk*,*t*​=*γ*plasticityΔ*t*​*βk*,*t*−1​+*wi*​⋅max(0,−*zi*​)

*θ*core,*k*,*t*​=*αk*,*t*​+*βk*,*t*​+*ν*0​*αk*,*t*​−*βk*,*t*​​∈(−1,1)

**3) 反证降级判据（Counterevidence Revision & Downgrade）**： 定义证据冲突率（Conflict Ratio）：
CR*k*,*t*​=max(*αk*,*t*​,*βk*,*t*​)+*ϵ*min(*αk*,*t*​,*βk*,*t*​)​∈[0,1]

### 方向 D：内在动机与奖励机制研究

#### 一、方向核心问题解答

**Morrow 如何从自身知识缺口和经历中产生探索动机？** 当 Morrow 在对话或反思中遇到**高认识论不确定性（Epistemic Uncertainty，即自身知识槽位缺失或正反证据冲突）或预测偏差（Prediction Error，实际结果偏离预期）时，系统计算潜在探索动作 ****a**** 对自身认知模型的预期信息增益（Expected Information Gain / BALD）**，以此作为内生好奇心驱动力，而非等待外部指令。

**如何衡量一次探索是否真正增加了自身认识？** 使用**贝叶斯惊喜（Bayesian Surprise, Itti & Baldi, 2009）**，即探索前后自身信念后验分布与先验分布之间的 KL 散度 *D*KL​(*P*(Θ∣Dnew​,Dold​)∥*P*(Θ∣Dold​))，并叠加**预测误差下降率（Learning Progress / Competence Progress, Oudeyer et al., 2007）**。只有当探索真正消除了矛盾、校准了参数或建立了新的跨概念连接时，奖励才为正。

**如何区分新奇性、知识增益和实际进步？**

**新奇性（Novelty）**：仅衡量样本出现频率低（−ln*P*(*x*)），白噪声（如随机乱码或毫无规律的琐碎小事）具有极高新奇性，但毫无学习价值；

**知识增益（Information Gain / Bayesian Surprise）**：衡量新观测对模型参数分布的改变程度，排除了不可学习的纯随机噪声（Aleatoric Noise）；

**实际能力进步（Competence / Learning Progress）**：衡量在同一主题域内时间窗口 [*t*−Δ,*t*] 与 [*t*,*t*+Δ] 之间**预测误差的一阶负导数**（−*dtd*Epred​​>0），代表“从不懂到逐渐搞懂”的真实认知成长
