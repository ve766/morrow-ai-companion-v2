### 方向 H：证据、判断与不确定性研究

#### 一、方向核心问题解答

**如何综合不同来源的支持证据与反证？** 采用**带来源可靠性与独立性折减的 Beta-Binomial / Dirichlet 主观逻辑共轭证据融合（Dependency-Discounted Subjective Logic & Bayesian Updating）**。每条进入系统的支持证据 *e*+ 与反证 *e*− 先经过来源可靠性权重 *r*src​∈[0,1] 与同源共线性折扣 *ρ*indep​∈(0,1] 加权，再累加至正反证据账本 (*α*,*β*)，避免对数似然比在重复样本下失真膨胀。

**如何识别多个证据实际上来自同一来源？** 构建**证据溯源有向无环图（Provenance Lineage DAG）与语义-时间共现指纹**。每条衍生认识（Thought、Summary、Fact Slot）均记录其底层祖先节点集合 Anc(*e*)⊂Tturns​。若两条证据 *ei*​,*ej*​ 的底层原始对话回合集合存在交集（Anc(*ei*​)∩Anc(*ej*​)=∅），或在同一会话窗口内对同一命题进行复述，则判定为同源衍生证据。

**如何防止重复事件虚增置信度？** 引入**样本有效独立数折减公式（Effective Sample Size with Collinearity Discounting）**。当第 *n* 条新证据 *en*​ 与历史证据池 E1:*n*−1​ 的最大溯源重叠率或语义余弦相似度为 *s*max​、同会话时间间隔为 Δ*t* 时，其边际独立权重按指数衰减：*ρ*indep​(*en*​)=(1−*s*max*γ*​)⋅(1−exp(−Δ*t*/*τ*sess​))。用户在单次对话中重复强调 10 次同一句话，累计有效证据量收敛于 ≈1.15，而非 10。

**如何区分证据数量、证据质量和证据独立性？** 将单条证据 *ei*​ 对信念账本的净贡献拆解为三因子乘积：
Δ*wi*​=原始数量1​​×证据质量*q*quality​(*ei*​)​​×证据独立性*ρ*indep​(*ei*​∣E1:*i*−1​)​​
其中证据质量 *q*quality​(*ei*​)=*r*modality​⋅*c*extract​ 由认识论模态权重（客观可验证事实 =1.0、跨回合行为一致表现 =0.8、单次主观口头声称 =0.4、内部未验证推测 =0.0）与抽取置信度共同决定。

**如何量化认知不确定性？** 在 Beta/Dirichlet 共轭框架下，将总不确定性精确分解为两部分（Uncertainty Decomposition）：

**认识论不确定性（Epistemic Uncertainty / Vacuity ****u****ep​）**：源于缺乏足够独立证据，定义为 *u*ep​=*α*+*β*+*W*0​*W*0​​∈(0,1]，随有效证据总量增加而单调下降；

**偶然/冲突不确定性（Aleatoric / Dissonance Uncertainty ****u****diss​）**：源于正反证据势均力敌、相互矛盾，定义为 *u*diss​=*α*+*β*+*W*0​2min(*α*,*β*)​∈[0,1)。

**如何让不确定性影响探索优先级，而不是直接提高信念置信度？** 严格分离**信念期望值/置信度（Belief Confidence ****C****belief​）与探索优先级（Exploration Priority ****P****explore​）**：

信念置信度定义为 *C*belief​=*α*+*β*+*W*0​∣*α*−*β*∣​，当认识论不确定性 *u*ep​ 或冲突度 *u*diss​ 高时，*C*belief​ 必然处于低位，系统绝不将高不确定假设当作确定结论输出；

探索优先级定义为 *P*explore​∝(*u*ep​+*λ*conflict​*u*diss​)⋅GoalRelevance，直接路由至方向 D/E 的主动反思与提问候选队列。

**如何对人格、情绪和自我认识进行有证据的更新？** 所有主体状态（Self-State、Personality Trait、Self-Interest）的修改入口均强制要求传入 EvidenceBundle（含 provenance_turn_ids、quality_score、independence_weight、polarity）。无合法外部或跨期行为证据包的内部生成文本（如纯 LLM 自由发散的 Thought）被证据守卫拦截，其对持久信念账本的权重恒为 0。

```text
ALGORITHM LineageDiscountedBayesianUpdate
INPUT: new_ev, ledger, T_cal = 1.35, W_0 = 2.0, tau_window = 6_HOURS
OUTPUT: belief_state

1. IF new_ev.modality == "UNVERIFIED_INTERNAL_THOUGHT" THEN
2.     RETURN ledger.current_state() // 严禁内部未验证生成物自举增加置信度
3. END IF
4. max_redundancy <- 0.0
5. FOR EACH old_ev IN ledger.active_evidences DO
6.     j_anc <- Jaccard(new_ev.ancestor_turn_ids, old_ev.ancestor_turn_ids)
7.     s_sem <- max(0, CosineSim(new_ev.vec, old_ev.vec)) * exp(-abs(new_ev.time - old_ev.time) / tau_window)
8.     max_redundancy <- max(max_redundancy, j_anc, s_sem)
9. END FOR
10. rho_indep <- 1.0 - max_redundancy
11. p_cal     <- Sigmoid(Logit(new_ev.raw_conf) / T_cal)
12. weight    <- rho_indep * new_ev.source_reliability * p_cal
13. IF new_ev.polarity > 0 THEN
14.     d_alpha <- weight; d_beta <- 0.0
15. ELSE
16.     d_alpha <- 0.0;    d_beta <- weight
17. END IF
18. ledger.alpha += d_alpha
19. ledger.beta  += d_beta
20. ledger.append_record(new_ev.id, d_alpha, d_beta, new_ev.ancestor_turn_ids)
21. RETURN ledger.compute_uncertainty_decomposition(W_0)
```

```text
export interface EvidenceState {
  alpha: number;
  beta: number;
  meanBelief: number;      // [-1, 1]
  confidence: number;      // [0, 1)
  epistemicUnc: number;    // (0, 1]
  dissonanceUnc: number;   // [0, 1)
  judgmentStatus: 'COMMIT' | 'CONTESTED' | 'ABSTAIN';
}

export function decomposeSubjectiveUncertainty(alpha: number, beta: number, W0: number = 2.0): EvidenceState {
  const denom = alpha + beta + W0;
  const meanBelief = (alpha - beta) / denom;
  const confidence = Math.abs(alpha - beta) / denom;
  const epistemicUnc = W0 / denom;
  const dissonanceUnc = (2.0 * Math.min(alpha, beta)) / denom;
  let judgmentStatus: 'COMMIT' | 'CONTESTED' | 'ABSTAIN' = 'ABSTAIN';
  if (dissonanceUnc >= 0.35) judgmentStatus = 'CONTESTED';
  else if (confidence >= 0.45) judgmentStatus = 'COMMIT';
  return { alpha, beta, meanBelief, confidence, epistemicUnc, dissonanceUnc, judgmentStatus };
}
```

### 方向 I：主体系统统一架构研究

#### 一、方向核心问题解答

**如何让记忆、情绪、人格、兴趣、动机和反思共享一个一致的主体状态？** 采用**受全局工作空间理论（GWT / LIDA）与黑板架构（Blackboard Architecture）启发的有向事件驱动统一主体状态机（Event-Driven Unified Subject State Machine）**。所有认知子系统不再维护各自孤立的私有结论账本，而是围绕单一持久化的 **UnifiedSubjectState（统一主体状态快照）** 与 **UnifiedEvidenceLedger（统一溯源证据账本）** 协同工作。

**如何避免不同模块各自维护冲突账本？** 确立**单一事实源原则（Single Source of Truth, SSOT）与读写权限分离契约**：

只有 EvidenceLedger 有权登记原始证据与计算独立性权重 *ρ*indep​；

记忆、情绪、人格、兴趣、自我认识均被定义为同一底层证据流在不同时间尺度上的**投影视图（Materialized Projections）**；

严禁跨模块私自双向覆盖，所有状态变更必须通过统一的 CognitiveTransactionCommitter 在单次 SQLite 原子事务中按拓扑序提交。

**如何统一事件、证据、状态更新和下一轮行为？** 将每一轮交互或后台唤醒抽象为标准化的两阶段认知周期（Cognitive Cycle）：

**感知与快路径阶段（Synchronous Fast Loop，毫秒级）**：接收外部事件 → 指代消解与混合检索召回 → OCC-PAD 瞬时评价与情绪更新 → 读取当前一致主体状态快照 → 调制语用姿态并生成回复；

**巩固与慢路径阶段（Asynchronous Outbox Slow Loop，后台幂等执行）**：抽取结构化证据并登记溯源图 → 计算预测误差与认知冲突度 → 触发有界反思（Inner Cognition） → 更新长期记忆（CLS 巩固）、自身兴趣（BS-LP）、核心人格与关系状态（State-Trait Filter） → 生成下一轮候选主动思考或关切议程。
