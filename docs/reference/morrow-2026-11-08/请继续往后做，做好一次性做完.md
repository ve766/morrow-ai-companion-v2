### 一、方向核心问题解答（续）

**如何在本地低成本运行内部认知？（续）** 遵循**代数优先、小模型次之、LLM 按需门控（Algebra-First, Small-ONNX-Second, LLM-Last）**的三级算力漏斗原则：

**第 1 级（纯代数闭式更新，占比 >85%，耗时 <1 ms）**：情绪 OU 微分衰减、主观逻辑 (*b*,*d*,*u*) 证据累加、状态-特质卡尔曼/Beta 更新、ACT-R 幂律遗忘计算、Hopfield 冲突能量与学习进步率计算全部由本地 TypeScript/Rust 标量与稀疏矩阵运算完成；

**第 2 级（本地量化 ONNX 小模型，占比 ~12%，耗时 5~45 ms）**：稠密向量编码（BGE-small INT8）、Cross-Encoder 重排与 NLI 矛盾检测在 CPU 上通过 ONNX Runtime 本地执行；

**第 3 级（LLM 深度推演，占比 <3%，由 VoI 严格门控）**：仅当第 1、2 级检测到高冲突能量 *C*conflict​>*τ* 且计算净价值 VoC*s*​>0 时，才通过异步 Outbox 唤醒单步结构化 LLM 生成溯因假设或语义巩固摘要。

**如何确保内部思考和外部工具执行拥有不同的权限边界？** 在统一架构中实施**认知-行动能力沙盒隔离（Cognitive-Action Capability Airgap）**：

**内部认知域（Inner Cognition Domain）**：仅拥有对本地记忆库、假设账本与 UnifiedSubjectState 候选暂存区的只读/沙盒写权限，严禁直接调用任何外部网络 API、系统文件修改或主动向用户发送未受控消息；

**外部行动域（External Expression & Action Domain）**：必须经过 Consent & Boundary Gate（复用 PR #70 的 Consent 门控机制）审批，任何外部表达或操作均只能读取已提交的主体状态快照。

**哪些认知架构适合借鉴，哪些过于复杂或不适合 Morrow？**

**适合借鉴**：**LIDA（全局工作空间广播 + 认知周期分相）**、**ACT-R（幂律记忆激活与缓冲器交互）**、**黑板架构（Blackboard，多专家模块围绕共享状态读写）以及预测加工（Predictive Processing，用预测误差驱动自下而上修正）**；

**不适合直接照搬**：完整版 Soar（全符号产生式规则与 Universal Subgoaling）对自然语言开放域对话的规则维护成本过高；纯自由能主动推断（Full Variational Free Energy Active Inference with POMDP 树搜索）在连续高维文本空间中的变分边缘化计算过于昂贵且难以工程调试，仅适合提取其“精度加权预测误差 + 信息增益”的标量简化形式接入。

| **核心差异** | 将人格视为固定的五个静态维度分值（OCEAN），假设成年后基本不变。 | 将特质定义为短期状态（States）在跨情境下的密度分布参数，区分瞬时状态与长期倾向。 | 将人格特质建模为带正反证据计数 (*α*,*β*) 与不确定性方差的潜在后验分布。 |
| **适用条件** | 静态角色卡片设定（Character Card）或问卷心理测量。 | 需要分离短期情绪波动、情境适配与长期稳定倾向的纵向陪伴系统。 | 需要严格控制证据门槛、支持反证降级与错误记忆撤回回滚的主体认知系统。 |
| **优势** | 心理学维度划分通用性强。 | 解决了“状态波动 vs. 核心特质”的时间尺度混同问题。 | 原生量化置信度与可塑性 Π*t*​=*wi*​/*N*eff​，完美支持反证修正与溯源回滚。 |
| **劣势** | 无法表达从经历中自然成长，也无法处理证据冲突。 | 连续时间结构方程（CT-SEM）若全量拟合历史轨迹则计算较重。 | 冷启动期因先验等效样本量 *ν*0​ 较大，特质演化较慢（符合设计预期）。 |
| **工程成本** | 极低（静态配置）。 | 中低（状态-特质双层滤波）。 | 低（Beta-高斯共轭闭式更新，耗时 <0.05 ms）。 |
| **与现有 Morrow 关系** | 仅可作为特质维度的命名参考。 | 直接对应 personality-growth-runtime-v2.md 的状态与风格解耦需求。 | 为 Morrow 现有人格成长折叠提供严格的数学证据账本与防污染守卫。 |
| **推荐策略** | **仅保留维度语义参考，不采用静态模式** | **组合采用**（采用其状态-特质-适配三层分离结构） | **组合采用**（作为核心更新方程，组成算法 C1） |

### 4. 第四组：内在动机与探索驱动算法对比（方向 D）
