### 三、最终算法分级与研发优先级总表（续）

#### 第二优先级：适合后续迭代升级的 10 项算法与子机制（续）

**算法 F1（核心巩固层）**：基于互补学习系统（CLS）的情景记忆向语义认识离线巩固晋升算法（分级：L1 / 证据等级：E1）——在后台空闲窗口将跨期重复验证的情景片段聚类蒸馏为长期语义槽位。

**算法 F1-Sub（自适应遗忘层）**：情绪唤醒度与重要性调制的 ACT-R 幂律自适应遗忘与间隔强化方程（分级：L2 / 证据等级：E1）——替代简单单指数衰减，保留跨时间间隔提取的高价值经历并软归档低价值寒暄。

**算法 F1-Bitemporal（双时态演进层）**：双时态知识表示（Valid-Time vs. Transaction-Time）与历史状态覆盖转移机（分级：L1 / 证据等级：E1）——解决用户状态变更（如换工作、搬家）时“保留历史真实性”与“维护当前有效性”的冲突。

**算法 D1（内生好奇心层）**：结合贝叶斯惊喜（KL 信息增益）与学习进步率（IAC-LP）的有界内在动机与自身兴趣模型（分级：L1 / 证据等级：E2）——严格剥离“用户高频谈论的话题”与“Morrow 自身获得认知成长的探索兴趣”，免疫白噪声陷阱。

**算法 G1（社会认知与边界层）**：基于二阶心智理论（ToM）自他信念分离（JSD 散度）与四维主观逻辑（熟悉度、温暖度、可靠性、边界健康度）的关系连续性模型（分级：L2 / 证据等级：E2）——区分“理解用户观点”与“认同并内化为自身观点”，提供反迎合与反依赖边界守卫。

**算法 A2（多跳联想层）**：基于海马体索引理论与个性化 PageRank（PPR / HippoRAG 范式）的联想记忆图谱检索（分级：L2 / 证据等级：E2）——盘活现有 Fact Slot 实体关系，通过稀疏矩阵幂迭代实现 1~3 跳跨事件联想召回。

**算法 I1（统一认知闭环层）**：基于全局工作空间（GWT/LIDA）显著性竞争广播与精度加权预测误差调度的事件驱动统一主体状态机（分级：L1 / 证据等级：E2）——打通前向预期登记、结果核验与快慢双环协调。

**算法 A1-Sub1（指代与焦点追踪层）**：结合中心理论（Centering Theory）活动实体焦点栈的对话指代消解与查询重写器（分级：L2 / 证据等级：E2）——解决多轮对话中代词省略、隐含主语与跨轮主题延续的检索失焦问题。

**算法 A1-Sub2（冗余抑制与认识论过滤层）**：最大边缘相关性（MMR）多样性重排与认识论模态标签过滤（FACT / PREFERENCE / OPINION / HYPOTHESIS / RETRACTED_ERROR）（分级：L2 / 证据等级：E1）——防止同质化记忆挤占上下文窗口及历史撤回记录重入 Prompt。

**算法 B1-Sub（认知重评层）**：基于慢路径反思归因修正的认知重评脉冲调节器（Cognitive Reappraisal Modulator）（分级：L3 / 证据等级：E2）——当内部反思发现先前情绪源于误解、反讽或外部归因时，注入反向修正量 *δ*I*t*​ 平滑平复情绪状态。

#### 长期储备（L3 / L4）：值得持续跟踪但近期不必强行接入的研究方向

| --- | --- | --- | --- | --- |
| **RES-01** | **细粒度晚期交互检索** (Late Interaction / ColBERTv2 多向量检索) | L3 / E1 | 通过 Token 级 MaxSim 算子兼顾双塔检索的速度与交叉注意力的细粒度词项匹配能力。 | 每个记忆条目需存储数十个 Token 向量，存储体积膨胀约 15~30 倍；在 Morrow 万级记忆规模下，算法 A1（Bi-Encoder + Top-20 Cross-Encoder）已足够覆盖精度需求。待未来记忆库突破百万级时再评估引入。 |
| **RES-02** | **计算语用学递归理性言语行为模型** (Recursive Rational Speech Act, Multi-Step RSA) | L3 / E2 | 通过递归求解听者与说者的贝叶斯博弈不动点，精细建模高阶反讽、委婉语与社交潜台词。 | 多步递归边缘化需要枚举封闭候选话语集，在开放域生成中计算开销较大；当前可先用分类器特征配合算法 G1 的一阶状态分离，待本地轻量语用推理小模型成熟后升级。 |
| **RES-03** | **对话反事实因果推断与结构因果模型** (Structural Causal Models & Counterfactual Reasoning) | L4 / E3 | 在自我反思中构造“如果当时我采取另一种回应，用户的反应会如何（*P*(*Ydo*(*x*)​∣*x*′,*y*′)）”的反事实推演。 | 自然语言对话缺乏受控干预实验条件，未观测混杂因子（Unobserved Confounders）极多，纯文本反事实推断容易退化为缺乏可验证证据支撑的 LLM 自由编造（证据等级仅 E3/E4）。 |
| **RES-04** | **子模函数优化的自传体长周期篇章摘要** (Submodular Optimization for Autobiographical Timeline Summarization) | L3 / E2 | 在给定 Token 预算下最大化自传体记忆摘要的覆盖度（Coverage）与多样性（Diversity），具有 (1−1/*e*) 近似比保证。 | 适合在 Morrow 积累数月以上真实交互数据后，用于生成“年度/月度共同经历回顾”或深层身份叙事锚点，非近期核心痛点。 |
| **RES-05** | **部分可观测马尔可夫决策过程下的主动推断规划** (Variational Active Inference & Expected Free Energy Planning) | L4 / E3 | 在理论上将认识论探索价值（Epistemic Value）与实用目标价值（Pragmatic Value）统一于单一变分自由能泛函最小化。 | 完整 POMDP 树搜索在开放语言空间中状态转移矩阵不可枚举；本研究已将其核心数学精髓（精度加权预测误差 *ξt*​ + 信息增益 *S*BS​）提取为标量闭式算法 D1/E1/I1，无需引入沉重的完整变分采样框架。 |

| **2** | **经典 Dempster-Shafer 证据理论正交和合成** (Classic DST Combination Rule) | 方向 H | **数学缺陷否决**：① 在正反证据高度冲突时，Dempster 归一化因子会导致著名的 **Zadeh 悖论**（完全忽略高冲突主导项，将 100% 信任错误赋给极小概率的一致旁支）；② 辨识框架幂集复杂度为 *O*(2∣Θ∣)，且经典正交和假设证据完全独立、不支持同源共线性折减与 O(1) 逆向撤回。采用算法 H1（带溯源折减的主观逻辑 Beta/Dirichlet 模型）全面优于 DST。 |
| **3** | **赋能最大化内在动机** (Empowerment Maximization, max*I*(*At*​;*St*+*k*​)) | 方向 D | **伦理红线与计算复杂度双重否决**：① Empowerment 的数学本质是最大化智能体动作对未来环境状态的通道控制容量，在人机伴侣场景中极易异化为“诱导用户产生可预测反应、操控对话走向或制造用户情感依赖”，直接违反任务书第四节方向 D 的禁令；② 高维文本空间中变分互信息估计（如 MINE）计算成本极高且不稳定。 |
| **4** | **二维环形情感模型** (2D Circumplex Model of Affect) | 方向 B | **表征降级否决**：仅含效价（Valence）与唤醒度（Arousal），缺失关键的第三维 **Dominance（支配感/控制感/自主性）**。这会导致系统无法区分“愤怒/坚定守护边界（负效价、高唤醒、高控制）”与“恐慌/无助迎合（负效价、高唤醒、低控制）”，且相对于 Morrow 现有的三维情绪状态属于倒退。 |
| **5** | **全符号产生式规则认知架构** (Full Soar / Full Symbolic Production Systems) | 方向 I | **维护成本否决**：全符号架构要求将所有领域知识与推理步骤手工编码为严格的 IF-THEN 产生式规则，面对开放域日常自然语言对话时会出现规则组合爆炸与脆弱性断裂，不适合作为伴侣主体的核心推理引擎。 |
| **6** | **以用户留存、互动时长、赞美或顺从度为奖励的强化学习** (Engagement / Sycophancy RLHF Reward) | 方向 D / G | **主体性与安全红线否决**：任务书第四节与第七节明确禁止。此类外部讨好奖励会迅速摧毁 Morrow 的独立判断能力（方向 H）与核心人格稳定性（方向 C），使其退化为无原则迎合的应声虫。 |
