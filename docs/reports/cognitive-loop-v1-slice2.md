## 3. 算法、参数与边界

**事实槽位（派生，不持久化）**：`subject` 固定为 `user`；`predicate` 取 `residence / employer / job_role / study / preference / goal / name / age / project_code / health`；`value` 为标记词之后的剩余文本（去标点、去前导「是/为/叫」、保留紧邻的否定）；问句（`哪里/什么/多少/吗`）返回空 value 并标记 `question`。无法命名谓词时返回 `null`，调用方按「不可判定」处理，不猜测。

**评分**：

```
score(q,m) = 1.00·S_slot + 1.00·min(1, contentOverlap/2) + 0.25·S_temporal + 0.20·S_source
```

- `S_slot`：谓词相同且（查询是问句 或 两个 value 不冲突）。
- `contentOverlap`：查询内容词（非框架、非跨框架二元组）命中数。
- `S_temporal`：查询与记忆共享时间词（今天/明天/下周/截止…）。
- `S_source`：用户直接输入 1.0，模型推断 0.5。

**放行条件不是分数阈值**，而是「短语命中 或 至少一个内容词 或 槽位命中」；框架词、时间词只影响排序。权重是手工设定并在固定夹具上验证的**确定性排序参数，不是概率**。

**边界**：撤回、超敏感、非 active 记录在评分前被排除；冲突判定与相关性分开（两条都可能相关且互相矛盾）。

## 4. 迁移与兼容

无 schema 变更、无迁移、无新表、无新依赖。槽位是读取时计算，记忆被更正或撤回后自动改变。`ContextMemory` 新增字段为可选，既有构造点（如 `provider-policy.test.ts`）无需改动。

## 7. 已知限制与回滚

1. 谓词规则是确定性的窄分类器，未识别的句子不参与槽位匹配，只走词法路径。
2. 词法仍是主要召回来源：只共享单个汉字不会命中。
3. 冲突只在「同谓词 + 值不可互相包含 + 极性一致」时判定；`杭州`/`杭州市` 视为同值，`住杭州`/`住浙江省杭州市` 这类层级关系会被判为冲突（保守方向，宁可让模型澄清）。
4. 时间语义只做「共享时间词」的弱加权，没有真正的时间区间推理。
5. 0.5B 模型的证据使用率 6/10，不代表产品级质量。
6. 回滚：删除分支即可；无迁移、无数据格式变化。
