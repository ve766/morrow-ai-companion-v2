## 2. 三个缺陷：复现、根因、修复

### P1 谓词识别与取值混在一起

| 复现 | 修复前 | 根因 | 修复后 |
|---|---|---|---|
| `我今年30岁。` | `value=''`、`kind=question` | 年龄正则把 `30岁` 整段吃掉，剩余为空 | `value='30'`、`kind=assertion` |
| `我对花生严重过敏。` | `value=''`、`kind=question` | 过敏宾语在标记词**之前** | `value='花生'`、`kind=assertion` |
| `我在学习 Blender。` | `value='习blender'` | `在学` 在更早位置先匹配，留下「习」 | `value='blender'`（`在学(?!习)`） |
| `我今年多少岁？` | `null` | 无数字时整条规则不命中 | `kind=question` |

修复：每个谓词独立 `extractor`，谓词识别、取值、问句判定三步分开；新增 `kind: assertion | question | negated | uncertain`；否定记在 `kind` 而非拼进字符串；假设/引用/传闻标记为 `uncertain` 且不取值。年龄、姓名、居住、任职、学习、健康、偏好、目标、项目代号全部保留，并新增 `schedule`（安排/日程/会议/出差/预约/复查/截止）。

### P2 时间词与框架词两套列表

| 复现 | 修复前 | 根因 | 修复后 |
|---|---|---|---|
| `去年发生了什么？` 召回 `我去年去过成都。` | 误召回 | `去年` 不在 `frameWords`，作为内容词计入 | 不召回 |
| `我下周有哪些安排？` 漏掉 `我下周要去上海参加行业会议。` | 漏召回 | 无 `schedule` 槽位，词面也不重合 | 召回（槽位+时间兼容） |
| 同一查询召回 `我明天要去医院复查。` | 误召回 | 问句槽位只看谓词，不看时间 | 不召回（时间不兼容） |

修复：`weakWords = frameWords ∪ timeWords`，两处使用同一列表；`frameCoverage()` 按位置标记弱词，弱词只参与排序、不能单独放行；时间兼容性要求「双方都有时间词时必须共享其一」，无时间词一侧不受限。

### P3 字符串包含被当作等价

| 复现 | 修复前 | 修复后 |
|---|---|---|
| `喜欢猫` / `喜欢猫狗` | 判为同值（包含） | `uncertain`（既不合并也不判冲突） |
| `杭州` / `杭州市` | 同值 | `equivalent`（明确的地点后缀规则） |
| `杭州` / `大阪` | 冲突 | `conflict` |
| `喜欢` / `不喜欢` | 未区分极性 | `conflict` |

修复：`compareFactValues()` 返回 `equivalent | conflict | uncertain`；`equivalent` 只来自明确规范化（地点后缀、全半角、助词），包含关系一律 `uncertain`，极性不同直接 `conflict`，不同谓词或任一侧为问句/空值 → `uncertain`。`slotsConflict()` 只在 `conflict` 时为真；装配器只用 `equivalent` 或问句做槽位准入。

## 3. 评分与准入（未改公式）

`score = 1.00·S_slot + 1.00·min(1, contentOverlap/2) + 0.25·S_temporal + 0.20·S_source`

准入仍来自「短语 / 内容词 / 槽位」，时间、框架、来源权重不能单独放行。本轮只改 `S_slot` 的成立条件（值等价或问句 + 时间兼容）。权重是确定性排序参数，不是概率。

## 6. 未解决问题与限制

1. `schedule` 谓词靠事件名词匹配（会议/复查/安排/截止…），「明天要交报告」这类没有标记词的事件不会进入槽位，只能走词法。
2. 时间兼容只比较字面标记，没有区间推理；「下周」与「周三」不会被认为相关。
3. 地点等价只处理后缀（市/省/区/县/镇/街道），层级地址仍会被判 `conflict`（保守方向）。
4. 单个汉字重合仍不召回；词法仍是主要召回来源。
5. 模型层能力问题未解决（0.5B）。
